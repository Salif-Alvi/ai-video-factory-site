Privacy policy

Last updated: 20 November 2026

What this is

AI Video Factory is a private tool operated by a single person. It is used only with the operator's own Google account, YouTube channels and Instagram accounts. It has no public users, no sign-up and no advertising.

What the tool accesses

When the operator signs in with Google, the tool asks for permission to: upload videos to the operator's own YouTube channels, read the operator's own channel statistics, and read comments on the operator's own videos. Instagram access works the same way for the operator's own Instagram accounts.

What is stored

  • Sign-in tokens for the operator's own accounts, stored privately on systems controlled by the operator.
  • Statistics about the operator's own videos (views, watch time).
  • Text of comments on the operator's own videos, used only to count audience votes and to prepare replies.

The tool does not collect, sell, share or publish personal information about any other person. It does not use data from Google or YouTube for advertising and does not transfer it to third parties.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions. Stored tokens are then deleted by the operator.
